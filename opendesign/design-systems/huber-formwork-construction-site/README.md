# Huber Formwork — Construction Site

A reusable OpenDesign package for Huber Formwork — Construction Site.

## Product Overview

Signal-red formwork brand, sister to Huber Bau GmbH (Ravensburg). Formwork is the temporary structural mould into which concrete is poured — planks, walers, ties, props. The brand voice should feel like a well-run job site: precise, enginee This design-system package is designed for product, app, workspace, and platform surfaces that need a reusable visual direction rather than a one-off mockup. It provides a concrete token layer, focused preview cards, and an applied UI kit so future agents can build interfaces with the same hierarchy, density, component roles, and interaction rules captured in DESIGN.md.
